## Интересные факты о мультфильме "Лило и Стич"
1. Первоначальный сюжет. По задумке Стич должен был быть межзвёздным гангстером, который во время одного из набегов бросил члена своей банды, Джамбу. В качестве локации планировался маленький отдалённый городок в Техасе, а не остров Кауаи.	
2. Использование акварельных фонов. «Лило и Стич» стал первым полнометражным анимационным фильмом студии Дисней, где используются фоны, нарисованные акварелью.
3. Дизайн большинства эпизодически появляющихся инопланетян был вдохновлён персонажами «Винни-Пуха». Включая Пятачка, Тигру и Крошку Ру.
4. Имя «Лило» переводится с гавайского как «Потерянная». Название одной из песен, «He Mele No Lilo», можно вольно перевести как «Колыбельная тех, кто потерялся».
5. У Стича отсутствуют зрачки, поэтому передать его эмоции становится сложной задачей. Компенсировать эту особенность создатели постарались очень выразительными движениями и жестикуляцией.
6. В книге «Гадкий утёнок», которую читают Лило и Стич, были использованы иллюстрации из старой диснеевской адаптации этой истории.
